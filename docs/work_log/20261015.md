## やったこと
### 置き場所を観測するモデルが固定ゴールで下がる理由の検討（ユーザーとの議論）
- 置き場所ランダムで、真値と RT-DETR の差は小さい（seed 0 で 29/30 と 28/30）。固定ゴールの 52/60 は真値での数字なので、下がる原因は検出器ではなく方策（掴む精度）
- 解釈: 元のモデルは置き場所固定に特化して学習しているので、固定ゴールでは有利（60/60）。ただし x2（デモ 701 本）でも固定ゴールは 27/30 で、
  固定位置付近の例の数だけでは説明しきれない。データ量・学習 step・観測（place_xy、物体位置の固定）も同時に変わっており、切り分けていない

### 固定ゴールのデータを混ぜる検証は行わない（ユーザー判断）
- 案: 元のモデルの置き場所固定のデモ（235 本）を置き場所ランダムのデモに混ぜて学習し直す
- ユーザーの指摘: そのまま混ぜると全体の約 4 割が固定ゴールになり、データが固定ゴールに寄りすぎる。総数をそろえて一部だけ入れ替える案も検討した
- 行わない理由: 置き場所ランダムにした目的は、どこに置き場所があっても運べる汎用的な方策にすること。固定ゴールのデータを混ぜるのは
  評価する条件に学習データを寄せるだけで、方策の改善ではない。混ぜる割合で固定ゴールとランダムの成績が入れ替わるだけと予想され、
  DART・x2 の「失敗する場所が移るだけ」と同じことになる
- 根本の課題は、課題を広げたときの掴む精度の余裕のなさ。対策の候補（掴む直前の位置合わせ、関節の追従の改善、物体基準の行動表現）は
  説明資料の 5 章に記載済みで、締切までには行わない
- 説明資料は「汎用化すると特化したモデルより元の課題の成功率が下がる（60/60 → 52/60、有意）。原因は掴む精度の余裕のなさと考えられ、DART でも解消しなかった」のままとする
