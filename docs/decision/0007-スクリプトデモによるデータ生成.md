# 0007 スクリプトデモによるデータ生成

- ステータス: 承認
- 日付: 2026-10-10

## コンテキスト
計画では 30〜50 エピソードをブラウザ手先テレオペで人手収録する予定だった。
一方で、変換〜学習〜評価のパイプライン検証や、ベースライン/改良版の比較実験を繰り返すには、条件を揃えたデータを素早く用意できる手段が必要。

## 決定
- 物体位置（`/task/object_pose`）を使う **スクリプトデモ**（min-jerk 補間のピック&プレース）を `pai_task_env/scripted_demo` として実装し、
  テレオペと同一のトピック（`/teleop/ee_target`, `/teleop/gripper` → IK → joint_trajectory）経由で収録する。
- 速度・経由高さ・把持位置に揺らぎを入れて多様性を持たせ、失敗エピソードは自動で `_discarded/` に退避する。
- 人手テレオペのデモは、ブラウザ UI の操作性評価（関節空間 vs 手先空間）と、スクリプトデモとの混合・比較に用いる。

## 結果
- 条件を揃えた 40 エピソードを自動で用意でき、比較実験が再現可能になる（seed 指定）。
- スクリプトデモは人の操作より規則的なため、学習は容易になる一方で人手デモへの汎化は別途確認が必要（レポートで明記する）。
