# 0008 学習ベースの物体検出器（RT-DETRv2 ＋ ドメインランダム化）

- ステータス: 承認・実装済み（2026-10-11。結果は docs/design/perception/detector.md）
- 日付: 2026-10-11

## コンテキスト
俯瞰カメラによる物体位置の推定は、赤色のしきい値処理と重心計算による簡易なもので、
「物体が赤い・照明が一定・カメラ位置が既知」というシミュレーション固有の前提に依存している。実機に近い条件でも物体位置を推定できるようにしたい。

## 決定
- 赤色検出を **学習した物体検出器** に置き換える。方策（ACT）は物体位置を入力とするため再学習は不要
- モデルは **RT-DETRv2**（Hugging Face transformers の `RTDetrV2ForObjectDetection`、重み `PekingU/rtdetr_v2_r18vd`）。
  いずれも **Apache-2.0**。Ultralytics（YOLO 系。Ultralytics 版 RT-DETR を含む）は AGPL-3.0 のため使わない
- 学習データは Gazebo で自動生成する。物体色・照明・机の模様・ダミー物体・カメラ取り付け誤差・画像ノイズをランダム化し（ドメインランダム化）、
  正解の bbox は物体の真の位置と形状を画像へ投影して自動で付ける
- bbox 中心を物体中心高さの平面へ逆投影して位置を求める。誤差が 5mm（実験4 で成功率が落ちない上限）を超える場合は補正を加える

## 結果（2026-10-11）
- 未使用の評価画像 300 枚で位置誤差 平均 0.28mm（全数検出）。赤色検出は 9/300 しか検出できない
- 見た目をランダム化したシーンで方策の成功率 30/30（赤色検出は 3/30）。元のシーンでも 30/30
- 実装上の判断: 学習には pai_training の pixi 環境（transformers 4.52 に RT-DETRv2 が含まれる）を使い、新しい依存は追加しない

## 結果（当初の見込み）
- 評価: ランダム化した未知の画像での位置誤差、ランダム化環境での方策成功率（赤色検出との比較）
- シミュレーション画像で学習するため実機での動作は保証しない。主張は「実機に近い変化に対して頑健」までとする
