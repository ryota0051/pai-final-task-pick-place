# 0005 物体位置の取得方式

- ステータス: 承認
- 日付: 2026-10-10

## コンテキスト
観測に物体位置を加えるため、Gazebo（Ignition Fortress）上の物体の姿勢を ROS トピックで得る必要がある。

## 検討
1. `/world/<w>/dynamic_pose/info`（Pose_V）を ros_gz_bridge で TFMessage に変換 → **エンティティ名が欠落**（child_frame_id が空）し、物体を特定できなかった。
2. PosePublisher system → リンク姿勢は親（モデル）基準で、モデルの world 姿勢が直接得られない。
3. **OdometryPublisher system を物体モデルに付与** → モデルの world 姿勢を `ignition.msgs.Odometry` で publish、`nav_msgs/Odometry` に bridge 可能。

## 決定
3 を採用。task_manager_node が world→crane_plus_base に変換して `/task/object_pose` を publish する。

## 結果
- 物体ごとにプラグイン設定が必要だが、トピックが物体名で一意に決まり扱いやすい。
- カメラ画像入力（発展）に移る場合も、成功判定用の真値として流用できる。
