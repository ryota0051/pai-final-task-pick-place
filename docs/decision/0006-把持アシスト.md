# 0006 把持アシスト（DetachableJoint）

- ステータス: 承認
- 日付: 2026-10-10

## コンテキスト
Ignition Gazebo で CRANE+ V2 のグリッパにより 4cm キューブを挟むと、両爪の接触は確認できる（関節角が計算上の接触角 0.19rad で停止）が、
持ち上げ時に滑落した。摩擦係数（mu=2）を上げても改善しなかった。gz_ros2_control の位置指令は弱い P 制御で把持力が小さいことが一因と考えられる。

## 決定
計画のリスク対策①に従い、**DetachableJoint による把持アシスト**を導入する。
- ロボット記述はラッパー xacro で link4–物体の DetachableJoint（attach/detach トピック）を追加
- 「グリッパが閉じている」かつ「把持中心（FK）と物体中心が 2cm 以内」で attach、グリッパを開くと detach（ヒステリシスあり）

## 理由
- 方策が学ぶべき「物体位置に応じて手を伸ばし、閉じ、運び、離す」という行動は保たれる（アシストは位置が合っていないと発動しない）。
- reach タスクへの縮小（リスク対策②）より課題としての価値が高い。

## 結果
- 物理的な把持力の再現は行わない（レポートで明記する）。
- 判定パラメータは `task.yaml` の `grasp_assist` で調整可能。`enabled: false` で無効化できる。
