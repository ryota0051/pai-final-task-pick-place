# 0001 リポジトリ構成

- ステータス: 承認
- 日付: 2026-10-10

## コンテキスト
ベース演習は `matsuolab/physicalai_teleop`（キーボード関節テレオペ）と `matsuolab/pai_training`（rosbag→LeRobot変換・ACT学習・推論）の2リポジトリで構成される。
最終課題では手先テレオペ・タスク環境・データ変換/推論の拡張を行う。

## 決定
- `final_task_1` を親リポジトリとし、docs・Docker設定・自作ROS 2パッケージ（`ros2_ws/src/`）を置く。
- `physicalai_teleop` は **取り込まない**。キーボードテレオペ1ファイルのみで、ブラウザ手先テレオペは自作パッケージ `pai_web_teleop` で新規実装する。操作性比較（関節空間 vs 手先空間）用に、Dockerイメージ内でupstreamをcloneしてビルドする。
- `pai_training` は変換・学習・推論の改修が必須のため、**自分のGitHub fork を `external/pai_training` に submodule** として取り込み、改修はfork側にコミットする。

## 結果
- upstreamとの差分がfork上で追跡でき、提出時に「サンプルからの改良点」を説明しやすい。
- submodule更新時は親リポジトリ側でも参照コミットを更新する必要がある。
