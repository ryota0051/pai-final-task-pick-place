# 0010 外乱入りのスクリプトデモ（DART）

- ステータス: 承認・実装済み、評価中（2026-10-14 ユーザー決定）
- 日付: 2026-10-14

## コンテキスト
置き場所ランダムの課題（ADR 0009）では、モデル・設定によらず成功率が 93〜97% で頭打ちになった。
失敗は毎回「方策の狙いが数 mm ずれ、指が物体の上面に乗る」もので、どこで起きるかはモデルによって変わる。
置き場所固定の元の課題でも、置き場所を観測するモデルは 85/90 と、元のモデルの 30/30 よりわずかに低い可能性がある（有意差なし）。
デモを倍（701 本）にしても改善しなかった（training_eval の実験12）。

スクリプトデモは計画どおりの軌道しか含まず、「ずれた状態から物体の真上へ戻す」例がない。
また、指令と現在の関節角がほぼ一致するため、方策は物体位置をあまり見なくても学習誤差を小さくできる。

## 決定
DART（Laskey et al., "DART: Noise Injection for Robust Imitation Learning", CoRL 2017）を使う。
スクリプトデモの **実行する手先目標にだけ外乱を足し、行動ラベルは外乱なしの指令** にする。

- 外乱は接近〜下降の区間だけに入れ、閉じる前に 0 に戻す（`scripted_policy.Disturbance`、設定 `scripted_demo.yaml` の `dart.*`）
  - 大きさは方策の狙いのずれ（実験12 の x2 で約 7.5mm）に合わせ、水平に半径 1cm の円内（一様）。0.5 秒ごとに引き直して滑らかにつなぐ
  - 運搬・配置、グリッパには入れない
- 外乱入りの指令は ee_teleop_node が作る（`/teleop/ee_disturbance` を受け取り、同じ IK で解く）。
  外乱なしの指令は `/teleop/expert_arm_command` に出し、変換設定の `topics.arm_command` でラベルに使う
  - スクリプトデモ側で IK を解いてラベルを作る案は、テレオペノードの pitch 緩和と結果がずれるおそれがあるので採らなかった
- 推論ノードは変換設定の指令トピックを出力先に使わない（`resolve_topics`）
- 比較のため、データ量・学習 step は A'（339 本程度・80k step）とそろえる
