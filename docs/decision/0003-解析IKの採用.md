# 0003 解析 IK の採用

- ステータス: 承認
- 日付: 2026-10-10

## コンテキスト
ブラウザから手先目標（xyz＋pitch）を 20Hz 程度で送り、関節指令へ変換する必要がある。
`crane_plus_with_table.launch.py` は MoveIt (move_group) も起動するため、MoveIt の IK/計画を使う選択肢もある。

## 決定
URDF のリンク長から導いた **解析 IK を自作**（`crane_plus_kinematics`）し、MoveIt は使わない。

## 理由
- CRANE+ V2 は ヨー＋平面 3 リンクで閉形式解が得られ、計算が軽く決定的（テレオペの高周期ループ・学習データの一貫性に有利）。
- ROS 非依存の純 Python にでき、ホストで TDD できる。
- MoveIt の計画は 1 指令ごとに時間がかかり、連続テレオペには不向き。

## 結果
- 衝突回避は行わない。作業空間クリップと関節リミットで安全側に倒す。
- tool_length は Gazebo でキャリブレーションが必要。
